# Dosificación de Mezclas de Concreto (ACI 211.1) 🏗️

Esta es una aplicación web interactiva construida con HTML, CSS y JavaScript puro que automatiza el proceso de diseño de mezclas de concreto basado en la normativa **ACI 211.1**.

## Características
- **Cálculo de F'cr y Relación A/C:** Asignación e interpolación automática.
- **Volúmenes Absolutos:** Calcula las proporciones de cemento, agua, grava y arena.
- **Peso Estimado:** Estima el peso teórico del concreto fresco (U).
- **Ajuste por Humedad:** Calcula automáticamente el aporte de agua de los agregados.

## Cómo usarlo
Simplemente abre el archivo `index.html` en cualquier navegador web, o visita la versión alojada en GitHub Pages. Ingresa las propiedades físicas de tus materiales y obtén los resultados al instante.
